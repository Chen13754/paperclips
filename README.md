# 环球回形针：文件存档版

游戏地址：**https://chen13754.github.io/paperclips/index2.html**

在现有中文版上增加「导出存档」「导入存档」，手机和电脑通过手动传输 JSON 文件接力游玩。无需安装插件，没有同步后台或存档上传服务。

## 使用

1. 在当前设备点击「导出存档」，下载 `paperclips-YYYY-MM-DD_HH-mm-ss.json`。
2. 通过聊天工具、数据线等方式把文件传到另一台设备。
3. 在另一台设备打开同一游戏网址，点击「导入存档」，选择文件，核对保存时间并确认。

导出会先保存点击时的进度，包含项目、策略、股票、量子芯片及周目信息。文件名使用设备当地时间，内部 `exportedAt` 使用 UTC ISO 时间。请保持设备时钟准确，按时间选择要继续的存档；不会自动合并两个设备的进度。

原游戏每约 25 秒自动保存到本浏览器，此行为保留。网页无法在关闭后持续运行游戏，也不会自动读取另一台设备的存档。

读档沿用原版流程：正在进行的锦标赛会重置，战斗列表会按原版 `refresh()` 清理；已经获得的资源、研究与周目正常恢复。

已经购买的量子芯片始终显示纯黑，每颗芯片每次手动计算提供基础 360 操作点，仍受原有内存容量和溢出规则影响。芯片仍需正常购买，不会自动点击。旧存档无需转换，原有芯片数量、其他进度和周目保留，读取后芯片波动值立即切换为固定收益；文件格式仍为版本 1。

界面使用暖白底、黑色终端和红／蓝／黄分类标记。桌面三列、平板两列保持不变。手机宽度小于 700px 时使用「主控台＋详情页」，底部只有「主控台、研究」两个入口，无需开启「桌面版网站」。

手机顶部常驻每秒产量及库存，解锁后补充操作点数／上限和 Yomi；产量使用浅黄色底。主控台按快速操作→当前阶段生产→策略比赛排列：量子计算、工作／思考、普通设备购买、探测器发射和比赛操作可直接使用。普通购买将设备名、数量及成本放在一起，批量购买和拆卸进入详情。

「生产详情」「电力详情」「计算与蜂群」「投资与比赛详情」「设计与战斗」入口就在所属模块旁，详情顶部显示完整名称和「返回主控台」。详情保留全部管理功能；常用控件只有一份，可通过返回入口定位到主控台对应操作。页面切换临时记住滚动位置，游戏继续运行；刷新默认主控台，界面状态不写入游戏存档。设备详情的数量和成本随原数据更新。

累计数字的自动生产显示最多每 100 毫秒合并更新一次，文字未变时不重写，保留同一个文字节点。手动制作、读档和结局变化立即更新；游戏计算、保存和导出继续使用实时数据。PC／iPad 保留原字号和完整千位分隔数字，数字与「回形针」标签固定分行，当前屏幕宽度下所需行高只增加、不反复收缩，终端不被数字区域拉高；读档、重开和宽度变化会重新计算。手机产量／库存保留原数量级写法与字号，预留三行数值高度，减少换行导致的顶部和滚动跳动。

累计产量与周目、终端历史合并在黑色终端的展开区，原网页迁移入口移至页面下方「存档迁移帮助」。字号保持不变，累计回形针数量完整换行，不截断。工作／思考滑块仍需按原规则完成「群体运算」研究才解锁。

补齐三个阶段、动态消息与结局的中文，并统一策略和探测器术语；数字、数量级、单位及有保留价值的原文继续保留，详见 [汉化约定](LOCALIZATION.md)。已移除游戏页中的 T 恤和手机版推广入口，原作署名及来源保留。

右上角「设置」可查看当前阶段、本周目运行时间、宇宙／模拟等级及加成。运行时间沿用游戏的 ticks 计时，不包含离线时间。

设置内的「资源增益」按当前阶段和解锁状态显示固定增量按钮，可补充资金、线材、可用回形针、物质、信任、创造力、Yomi、蜂群礼物和荣誉，并可补满标准操作点数或电池储电。增益不会直接改变阶段、研究、设备数量或累计产量；操作点数补满保留原有量子溢出。容量已满／为零时不能补满，结局拆卸期间暂停增益。无效数值、溢出和小于浮点精度的增益会提示而不修改数据。增益沿用原游戏自动保存，也可立即导出。

关键数值旁的问号可点击查看简短用途说明，再点同一问号、点击外部或按 Esc 收起。设置中的「显示数值说明」可隐藏全部问号，仅在本次打开页面期间生效，刷新恢复开启，不写入存档。

每次打开或刷新网页后，首次进入「资源增益」会提示首次游玩不建议使用，以免破坏探索和成长的体验。点击「了解风险，继续」后，本次网页内不再提示；取消或关闭不算确认，也不修改进度。提示状态只保存在当前页面内存中。

设置底部的「从头开始」需要再次点击「清空进度并重开」才执行，会清除本浏览器的当前进度和全部周目加成，恢复首次游玩状态。需要保留进度时请先取消并导出存档，已经导出的版本 1 文件仍可导入。关闭、取消、Esc 和点击弹窗外部均不执行重开；默认焦点放在取消。此操作只删除六个有效游戏存档键，不清除同一网站的其他数据。存储删除失败会回滚并保留当前运行中的游戏，恢复也失败时提示先导出、不要刷新。重开成功后刷新前暂停保存，避免旧进度被自动写回。结局中获得周目加成的重开仍沿用原规则。

已移除旧中文版的客服／广告脚本、Google Analytics 和百度统计，首页入口也已清理；正常游玩不自动请求外部站点。iPad 等触屏设备使用 touch-action: manipulation 减少连续点击触发双击放大，同时保留滚动、滑块和双指缩放，不需要关闭系统缩放。

存档键、游戏字段和 JSON 版本 1 保持不变；导入校验同时接受原游戏创造力解锁标记的布尔值和 0／1 写法。原网址中的浏览器存档会直接读取，版本 1 的文件存档可继续导入，历史英文名称只在显示时翻译。

导入会覆盖当前浏览器的进度；想保留当前进度时，先导出一份。无效文件或取消导入不会写入存档。写入失败时会恢复已经改动的存档键；如果浏览器连恢复写入也拒绝，请不要刷新或关闭游戏，并按页面提示处理。

## 迁移原网址的进度

打开电脑版顶部的「原网页进度迁移」（手机版在下方「存档迁移帮助」内），或访问：

https://chen13754.github.io/paperclips/migrate.html

帮助页提供电脑控制台脚本、安卓地址栏及脚本书签步骤。安卓地址栏操作将手动输入的 `javascript:` 与复制的正文分开，避免 Chrome 过滤粘贴前缀。原游戏勾选「桌面版网站」时也按相同步骤操作；新游戏无需勾选该选项。

脚本一运行就显示加载面板，工具就绪后由用户点击「导出存档」，在直接点击时发起下载。完全没有面板、工具加载失败、下载未出现对应不同的排查步骤。下载不可用时可显示 JSON 文本并手动复制为文件。帮助页也提供 Chrome USB 远程调试的一次性迁移办法。

脚本从本项目加载导出工具，在原游戏页面下载相同格式的文件，不删除原存档。需要网络读取静态脚本，但不会传输任何游戏进度。

不要清除原浏览器的数据，直到确认新版中的进度正确。脚本书签受具体浏览器支持限制；手机尺寸模拟不等同于安卓实机验证。

## 本地检查

使用已有 Node.js，无运行时依赖。测试依赖、缓存和浏览器测试文件均放在项目目录中：

```powershell
npm ci --cache .cache/npm --no-audit --no-fund
npm test
npm run test:browser
npm run test:design
npm run test:settings
npm run test:counter
```

浏览器测试使用电脑已安装的 Microsoft Edge，或通过 `PAPERCLIPS_BROWSER` 指定 Chromium 浏览器可执行文件，不下载浏览器。测试仅使用临时浏览器配置和临时本地预览服务，结束后关闭。GitHub Actions 仅发布网页资源，不发布测试文件、依赖、缓存或个人存档。

兼容性测试使用修改前代码生成的合成存档 `tests/fixtures/legacy-save-v1.json`，其中含负数和灰色芯片波动值；它不是个人存档，也不会发布到网站。

界面测试从上一版 `21a09a9` 的实际页面生成初期、人类商业、投资、地球及太空阶段的合成存档，在 320、390、430、699、700、768、1440 像素宽度下对比原生读档结果，检查导入、导出、刷新、操作按钮及布局。另外检查结局旧存档、主控台与详情的滚动记忆、普通／批量购买与拆卸、探测器发射和设计、后台生产、滑块解锁和反复切换手机／桌面宽度。测试输出位于忽略提交的 `test-results/`；验收记录见 [design-qa.md](design-qa.md)。新增设置检查覆盖三个阶段的固定增益、容量／精度／非法数值、原生自动保存及文件往返，320～1440px 下设置／说明的关闭、焦点、尺寸切换与本次页面开关，以及两种实际结局重开。无请求拦截的检查确认没有外部自动请求或弹出窗口。

数字显示专项检查对比修复前 0c7950d 的原生读档结果，覆盖 PC／iPad 尺寸 768／980／1024／1440px 和手机 320／390／430／699px：100 次静止循环不重写累计文字，持续生产按显示节奏合并、手动点击即时更新，巨大数字、结局文案、滚动位置、横竖尺寸切换和导出最新数据均正常。

重开专项检查覆盖三阶段进度、资源增益后的进度和周目加成；确认后清空并返回初始状态，自动保存临界时不写回旧进度，之前导出的文件可以恢复。逐个存档键模拟删除失败，检查回滚、读写权限被拒绝及恢复失败时保留内存进度并实际导出。警告覆盖取消、关闭、确认后的重复进入、刷新再提示以及不新增存档键；确认界面检查 320～1440px 尺寸、取消优先焦点与触控按钮大小。

这些检查使用隔离的浏览器配置，不接触日常浏览器中的存档。尚未经过安卓或 iPad 实机验证；触控与尺寸模拟使用 Chromium／Edge，不能替代 Safari 的实际手势测试。

## 存档格式

版本 1 使用 `{format: "paperclips-save", version: 1, exportedAt, storage}`。`storage` 保存原生 JSON 字符串：`saveGame`、`saveProjectsUses`、`saveProjectsFlags`、`saveProjectsActive`、`saveStratsActive` 和 `savePrestige`。没有周目信息时，`savePrestige` 为 `null`，导入时清除目标设备旧的周目信息。
