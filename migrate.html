把原网页进度带到新版

只需迁移一次。下面的脚本在原游戏页面中保存当前进度并下载 JSON 文件，不上传进度、不删除原存档，也不安装插件。之后在新版点击「导入存档」即可。

请使用原来玩游戏的浏览器打开 原游戏，先确认其中显示的是你要保留的进度。不同设备的旧进度分别导出，由你选择要继续的一份。

电脑：在原页面执行一次

  1. 复制下方脚本，在原游戏页面按 Ctrl＋Shift＋J 打开浏览器控制台。
  2. 粘贴并按回车，按浏览器提示确认粘贴操作。原游戏上会出现「原网页存档导出」面板，点击其中的「导出存档」下载文件。
  3. 打开新版游戏，点击「导入存档」，选择下载的文件。

安卓 Chrome：在原游戏地址栏执行

原游戏已勾选「桌面版网站」也可以按下面操作；这个选项不会自动运行导出脚本。新版游戏无需勾选该选项。

  1. 点击下方「安卓：复制脚本正文」。
  2. 回到有你进度的原游戏标签页，点击地址栏，清空原网址。
  3. 手动逐字输入 javascript:（英文半角冒号），再在其后粘贴刚才复制的正文。不要用「粘贴并前往」。
  4. 确认地址栏开头是 javascript:void(，点击键盘「前往／回车」。若变成搜索结果，请返回原游戏，重新检查前缀。
  5. 原游戏上应立即出现「脚本已执行，正在加载导出工具……」，随后显示「工具已就绪」。点击面板中的「导出存档」。
  6. 在下载记录或系统「下载」文件夹中找到 JSON 文件，再到新版点击「导入存档」。

Chrome 会过滤粘贴内容开头的 javascript:，所以这里将手动输入的前缀与复制的正文分开。Chromium 的相关说明。

也可使用脚本书签

  1. 先把本页加入书签，名称改为「回形针导出」。
  2. 点击「复制完整脚本」，编辑这个书签，把网址完整替换为脚本。开头必须保留 javascript:，然后保存。之前建过书签的，也需要替换为这次的新脚本。
  3. 打开原游戏页面，确认进度。在地址栏输入「回形针导出」，点击带书签标记的匹配项；不要进行搜索。
  4. 在出现的导出面板中点击「导出存档」。

仍然没有反应时

  • 完全没有面板：脚本入口尚未成功执行，无法据此判断存档是否能下载。可在原游戏地址栏手动输入 javascript:alert(1)，点击前往。正常应弹出数字 1；这个测试不修改存档。
  • 面板显示加载失败或一直加载：脚本已经执行，但工具未加载。检查网络后关闭面板，重新执行。
  • 面板已就绪，但下载没出现：点击「显示存档文本」，全选复制 JSON，传到电脑后保存为 .json 纯文本文件，再到新版导入。

如果连手动输入的测试也没有弹窗，可通过数据线做一次迁移：手机启用「开发者选项 → USB 调试」，连接电脑并允许调试；电脑 Chrome 打开 chrome://inspect/#devices，找到手机上的原游戏标签页并点击 Inspect，在它的 Console 中执行上面的完整脚本，再在手机出现的面板中导出。完成后可关闭 USB 调试。Chrome 官方操作说明与设备识别排查。

不同安卓浏览器对脚本入口的支持可能不同。已完成浏览器模拟检查，尚未经过安卓实机验证。迁移完成前请保留原浏览器数据。

之后怎样在两台设备间继续玩

在设备 A 点击「导出存档」→ 通过聊天工具或文件传输把 JSON 发到设备 B → 在设备 B 打开新版，点击「导入存档」。文件名带保存日期和时间，方便你选择最新的一份。

新版仍会在本浏览器自动保存进度。刷新后继续玩本地进度；跨设备接力需要手动导入文件。存档只存在你的浏览器与导出的文件中。
